# Varun Goud - Portfolio

Personal portfolio of Varun Goud, an AI/ML engineer and full-stack developer building AI-driven applications, REST APIs, and AI agents.

**Live site:** https://varunnn47.github.io/Portfolio/

## Built with

React, Vite, Tailwind CSS, and Framer Motion. Deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Run locally

```bash
npm install
npm run dev
```

## Updating content

Projects, experience, certifications, skills, and contact links all live in [`src/Data/portfolioData.js`](src/Data/portfolioData.js). The resume is [`public/Varun-Goud-Resume.pdf`](public/Varun-Goud-Resume.pdf).
